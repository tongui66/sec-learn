# 🐬 MySQL 网安学习站 v2 · 使用说明

> 定位：**零基础 → 查询 → 注入攻防 → 数据库加固**，20 章 + 80 题 + 12 个实验。
> 目标：不是「背会语法」，而是**学完能独立设计表、审计注入点、给一个库做加固**。
> 与 PHP 站是姊妹篇：PHP 站讲「怎么用代码操作数据库」，本站在数据库这一侧把语法、注入原理、权限加固打透。

---

## 一、怎么打开

- **电脑**：双击 `index.html`（推荐 Chrome / Edge）。
- **平板**：把整个 `mysql` 文件夹传到平板，用浏览器打开里面的 `index.html`。
- 全站离线可用，不需要联网，不需要安装任何东西。

## 五、跑起来（10 分钟）

1. 装 **XAMPP**，启动其中的 **MySQL**（Apache 可选）。
2. **把 mysql 命令加进 PATH**（关键一步）：XAMPP 的 mysql 命令默认不在 PATH，直接敲会报「不是内部或外部命令」。要么先 `cd C:\xampp\mysql\bin`，要么把该目录加进系统 PATH。
3. 建练习库：`mysql -u root < init.sql`（在 `code` 文件夹里执行）。
4. 进命令行：`mysql -u root` → `USE shop;` → 开始练习。
5. 图形界面：浏览器打开 `http://localhost/phpmyadmin` 也能看数据。

> 建好后可以自测：`SELECT COUNT(*) FROM user;` 应该返回 4。

## 六、每天 1 小时的推荐节奏

1. **30 分钟读 1 章**：重点不是背语法，是能说清「这条 SQL 如果被注入改写，会发生什么」。
2. **15 分钟做该章 4 道题**：错题会自动进错题本，错在哪就说明哪个概念只是「看着懂」。
3. **30 分钟进「实验」页动手**：SQL 是敲会的，不是看会的。
4. 学完点「✅ 学完了」，再回首页看自测清单能勾上几条。

> 20 章按这个节奏大约 3 周。**建议顺序学习**：第 13 章的注入要用到第 5-8 章的查询知识，第 16 章的文件读写要用到第 12 章的 secure_file_priv。第 2 章（建表）和第 12 章（备份）相对独立，可以插空提前学。

## 六点五、有 DVWA 的话，这样配合用

「实验」页右上角切到 **🎯 DVWA 靶场**，里面是按模块组织的实操手册，和课程章节一一对应：

| DVWA 模块 | 对应课程 | 你会学到 |
|---|---|---|
| SQL Injection（Low） | 第 13、14 章 | 判定 → 探列数 → UNION 拖库的完整实操 |
| 各模块的 View Source | 第 13.1、17 章 | 把打穿的过程和源码一行行对上 |

| SQL Injection（High） | 第 14 章 | 为什么 LIMIT 1 挡不住注入 |
| SQL Injection (Blind) | 第 15.1、15.2 节 | 布尔盲注与时间盲注 |

> 关键提示：DVWA 的 **Impossible 级别就是安全写法**，所以不用另找靶场，你就能在一个页面里完成「打穿 → 看源码 → 换级别 → 复测」的闭环。手册里每一步都写了「你应该看到什么」，照着对答案即可。
>
> 手册默认你已经装好 DVWA。如果还没跑起来，第 0 步写了三个要确认的地方（访问地址、数据库初始化、安全级别）。

## 七、怎么算「学到位了」

首页的**精通自测清单**（12 条）就是验收标准。其中最关键的几条：

- 能独立设计一张表：类型选对（金额用 DECIMAL）、约束加齐（主键/非空/唯一/外键/CHECK）；
- 能用 EXPLAIN 判断查询走没走索引，并说出哪些写法会让索引失效；
- 能判断注入类型，并说清 UNION 注入为什么要先探列数；
- 能用 information_schema 完成「库 → 表 → 列」的枚举；
- 能讲清 LOAD_FILE / INTO OUTFILE 的三大前提，以及它为什么能升级成 getshell；
- 能对一个真实站点做加固审计：最小权限、危险权限收回、不绑公网、日志与备份全部落地。

## ⚠️ 安全提醒

- 第 13-16 章讲注入与文件读写的原理，**目的是让你看懂并修复漏洞**。
- **所有注入语句、文件读写演示，只允许在你自己的本地 XAMPP / 靶场执行。**严禁对任何真实网站、学校系统、公司数据库测试——无论是否造成损失。
- 如果你审计的是公司或学校的真实系统，**只做只读检查**，任何修改都要先取得授权并走变更流程。
- 生产环境改数据库前：先备份 + 留恢复方案 + 保留回滚路径。
