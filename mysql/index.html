🧪 实验与靶场

环境准备（10 分钟）

1
装 XAMPP
启动其中的 MySQL（和 Apache）。自带 phpMyAdmin 图形界面，零配置即可用。
2
把 mysql 命令加进 PATH（关键一步）
XAMPP 装完 mysql 命令默认不在 PATH，直接敲会报「不是内部或外部命令」。要么先 cd C:\xampp\mysql\bin，要么把该目录加进系统 PATH。
3
建练习库
在 code 文件夹执行 mysql -u root < init.sql，建好 shop 库（用户 / 订单 / 商品表 + 测试数据）。后面的实验都拿它练。
4
两个配套 SQL 文件
init.sql：建库建表 + 造数据，所有实验的起点。
safe_queries.sql：注入原理演示 + 加固练习，只在你本地跑。
红线：第 13-16 章的注入语句、文件读写演示，只允许在你自己的本地 XAMPP / 靶场执行。禁止对任何真实网站、学校系统、公司数据库做测试——无论出于什么目的。学攻击原理是为了写出打不动的代码。
为什么把 DVWA 单独列一页：它自带 Low / Medium / High / Impossible 四个级别——Impossible 就是安全写法。所以你不用再另找靶场，就能走完「打穿 → 看源码 → 换个级别 → 看源码 → 打 Impossible 复测」的完整闭环。这正好补上文档式教程最大的短板：看不到运行结果、也看不到修复后的样子。
