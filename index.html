🔄 进度同步（手机 ↔ 电脑）

学习进度保存在浏览器本地，不同设备的进度是分开的。想在手机和电脑之间同步，用下面两个按钮： 在旧设备导出 → 在新设备导入即可。
导出内容包含：每门课的已学章节、打卡记录、练习答题记录、自测清单勾选。导入会覆盖当前设备的进度。

📱 手机上能做什么

  • 随时可以：看课程、做练习、查速查表和术语表、看实验步骤——只要打开这一个链接。
  • 需要在家里的网络：真正跑 PHP 代码、打 DVWA 靶场。因为靶场跑在你家虚拟机上（192.168.11.133），外出时连不上。
  • 建议加到主屏幕：浏览器菜单里选「添加到主屏幕」，以后一点就开，像 App 一样。
  • 进度记得同步：在手机上学的进度不会自动出现在电脑上，用上面的导出/导入。

⚠️ 安全提醒（重要）

这个站里的 php/code/ 文件夹包含「故意有漏洞」的 PHP 示例（命令执行、文件上传、反序列化等）。 它们只是源码文本，放在静态托管平台上不会被执行，所以是安全的。
  • 绝对不要把这个文件夹部署到任何会执行 PHP 的虚拟主机上——那等于把一台公开的靶机挂在网上。
  • 所有 payload 只能在你自己的虚拟机 / DVWA / 本地靶场里跑。
  • 严禁对任何未授权的真实系统做测试——学校网站、公司系统、公网任意站点都不行，不管有没有造成损失。
