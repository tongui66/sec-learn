# 🛡 网安学习台

五门自学课程的统一入口，纯静态站点（无后端、无外部依赖），可以部署到任意静态托管平台，手机 / 平板随时访问。

**已部署地址：<https://tongui66.github.io/sec-learn/>**

## 包含什么

| 目录 | 课程 | 规模 |
|---|---|---|
| `firewall/` | 防火墙 | 21 章 · 84 题 · 12 个实验 · 53 条术语 |
| `mysql/` | MySQL 数据库 | 20 章 · 80 题 · 12 个实验 · 8 个 DVWA 靶场模块 · 61 条术语 |
| `php/` | PHP 代码审计 | 24 章 · 96 题 · 12 个实验 · 8 个靶场模块 · 62 条术语 · 15 个可运行示例 |
| `python/` | Python 代码审计 | 20 章 · 80 题 · 12 个实验 · 10 段审计靶场 · 65 条术语 · 14 个可运行示例 |
| `english/` | 英语四级 · 精通道 | 20 章 · 80 题 · 12 个专项训练 · 10 组实战演练 · 77 条术语 · 300 核心词 |

`index.html`（根目录）是总入口：显示五门课的进度，并提供**进度导出 / 导入**（用于手机和电脑之间同步）。

## 怎么访问

**手机 / 平板**：浏览器打开 <https://tongui66.github.io/sec-learn/>，然后在浏览器菜单里选「添加到主屏幕」，以后一点就开，像 App 一样。

**电脑**：直接打开本地的 `index.html`，或者访问上面这个网址。两边进度独立，用总入口页的「导出/导入」同步。

## 怎么更新内容

课程有更新时，在本目录执行：

```bash
git add -A
git commit -m "更新课程内容"
git push
```

推送后 GitHub 会自动重新构建，一两分钟后刷新页面即可看到新内容。**学习进度不会丢**——它存在浏览器本地（localStorage），不在这些文件里。

> 提示：本仓库已单独关闭 git 代理（`http.proxy` 为空），因为全局代理 `127.0.0.1:7993` 未运行会导致推送失败。

## 备选：部署到 Cloudflare Pages

如果哪天想换一个国内访问更快的地址，可以：

1. 打开 <https://dash.cloudflare.com/> 登录（注意：新账号可能需要先完成邮箱验证才能部署）。
2. 左侧 **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
3. 项目名随便填，把本文件夹整个拖进去，点 **Deploy**。
4. 得到 `https://xxx.pages.dev` 网址。

## 进度同步（手机 ↔ 电脑）

学习进度保存在**浏览器本地**，不同设备、不同浏览器之间是互相独立的。同步方法：

1. 在旧设备打开总入口页 → 点「⬆ 导出进度」→ 复制文本框内容（或存成文件）；
2. 在新设备打开同一个页面 → 把内容粘到文本框 → 点「⬇ 导入进度」。

导出内容包括：已学章节、打卡记录、练习答题记录、自测清单勾选。

## ⚠️ 安全提醒

- `php/code/` 里包含**故意有漏洞的 PHP 示例**（命令执行、文件上传、反序列化等）。它们只是源码文本，放在静态托管平台上**不会被执行**，所以是安全的。
- **绝对不要**把这个文件夹部署到任何**会执行 PHP 的虚拟主机**上——那等于把一台公开的靶机挂在网上。
- `python/code/` 里同样包含**故意有漏洞的 Python 示例**（命令注入、反序列化、SSTI、路径穿越）。它们也只是源码文本，
  但**只允许在你自己的电脑、自己的虚拟环境里用 `py 文件名.py` 运行**。
- 所有 payload 只能在你自己的虚拟机 / DVWA / 本地靶场里跑。
- 严禁对任何未授权的真实系统做测试——不管有没有造成损失。

## 关于实验环境

PHP 课里「跑代码」和「打靶场」的部分，需要一台装了 phpStudy 的 Windows 虚拟机和一台 DVWA（本套课程用的是 `192.168.11.133`，在 VMware NAT 网络里）。

**Python 课不需要虚拟机**：本机装了 Python 3.14，用 `py` 命令（不是 `python`）就能跑全部实验。

- **在家**：手机连同一个 WiFi，可以配合电脑一起做实验。
- **在外面**：只能看课、做题、查速查表；实验等回家再做。
