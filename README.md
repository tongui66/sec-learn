# 🛡 网安学习台

三门自学课程的统一入口，纯静态站点（无后端、无外部依赖），可以部署到任意静态托管平台，手机 / 平板随时访问。

## 包含什么

| 目录 | 课程 | 规模 |
|---|---|---|
| `firewall/` | 防火墙 | 21 章 · 84 题 · 12 个实验 · 53 条术语 |
| `mysql/` | MySQL 数据库 | 20 章 · 80 题 · 12 个实验 · 8 个 DVWA 靶场模块 · 61 条术语 |
| `php/` | PHP 代码审计 | 24 章 · 96 题 · 12 个实验 · 8 个靶场模块 · 62 条术语 · 15 个可运行示例 |

`index.html`（根目录）是总入口：显示三门课的进度，并提供**进度导出 / 导入**（用于手机和电脑之间同步）。

## 部署到 Cloudflare Pages（推荐，5 分钟）

1. 打开 https://dash.cloudflare.com/ ，注册或登录（免费账号即可）。
2. 左侧选 **Workers & Pages** → **Create** → **Pages** → **Upload assets**。
3. 项目名随便填（例如 `sec-learn`）。
4. 把**这个文件夹整个拖进去**（或上传打包好的 zip）。
5. 点 **Deploy**，几十秒后会给你一个 `https://xxx.pages.dev` 的网址。

之后手机浏览器打开这个网址，菜单里选「添加到主屏幕」，就变成一个图标了。

## 部署到 GitHub Pages

1. 新建一个 **public** 仓库（免费账号的 Pages 只支持公开仓库）。
2. 把本文件夹里的所有文件上传到仓库根目录（网页版拖拽即可，不用装 git）。
3. 仓库 **Settings → Pages** → Source 选 `Deploy from a branch` → 分支选 `main`、目录选 `/ (root)` → Save。
4. 等一两分钟，访问 `https://你的用户名.github.io/仓库名/`。

> 国内访问 `github.io` 经常较慢甚至打不开，如果主要在国内用手机看，**Cloudflare Pages 的体验会好很多**。

## 更新内容

以后课程有更新，把新的文件夹重新上传覆盖即可。**进度数据不会丢**——它存在浏览器本地（localStorage），不在这些文件里。

## 进度同步（手机 ↔ 电脑）

学习进度保存在**浏览器本地**，不同设备、不同浏览器之间是互相独立的。同步方法：

1. 在旧设备打开总入口页 → 点「⬆ 导出进度」→ 复制文本框内容（或存成文件）；
2. 在新设备打开同一个页面 → 把内容粘到文本框 → 点「⬇ 导入进度」。

导出内容包括：已学章节、打卡记录、练习答题记录、自测清单勾选。

## ⚠️ 安全提醒

- `php/code/` 里包含**故意有漏洞的 PHP 示例**（命令执行、文件上传、反序列化等）。它们只是源码文本，放在静态托管平台上**不会被执行**，所以是安全的。
- **绝对不要**把这个文件夹部署到任何**会执行 PHP 的虚拟主机**上——那等于把一台公开的靶机挂在网上。
- 所有 payload 只能在你自己的虚拟机 / DVWA / 本地靶场里跑。
- 严禁对任何未授权的真实系统做测试——不管有没有造成损失。

## 关于实验环境

课程里「跑代码」和「打靶场」的部分，需要一台装了 phpStudy 的 Windows 虚拟机和一台 DVWA（本套课程用的是 `192.168.11.133`，在 VMware NAT 网络里）。

- **在家**：手机连同一个 WiFi，可以配合电脑一起做实验。
- **在外面**：只能看课、做题、查速查表；实验等回家再做。
