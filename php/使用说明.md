# 🐘 PHP 网安学习站 v2 · 使用说明

> 定位：**零基础 → 看懂源码 → 能独立做代码审计**。
> 规模：24 章 + 96 题 + 12 个实验 + 8 个 DVWA 靶场模块。
> 目标不是「会写 PHP」，而是：**给你一段陌生代码，你能标出输入点、找出危险函数、追出数据流、判断漏洞是否成立，并说出怎么修。**

## 一、你的环境（照这个来，别重装）

| 在哪 | 有什么 | 干什么用 |
|---|---|---|
| **本机**（这台 Windows） | 只有这些课程网页 | 看课、做题、查速查表 |
| **虚拟机 192.168.11.133** | phpStudy（Apache + PHP 5.4 + MySQL） | 跑 `code` 里的示例代码 |
| **同一台虚拟机** | DVWA v1.9（登录 admin / password） | 打靶场、对照源码 |

**为什么不在本机装 PHP**：本机根本没装 PHP，而虚拟机上已经有一整套能跑的环境。把 `code` 文件夹复制到虚拟机的 `C:\phpstudy\WWW\php\` 下，用本机浏览器访问 `http://192.168.11.133/php/xxx.php` 就行。

**两条注意事项**：

1. 虚拟机里的 PHP 是 **5.4**、DVWA 是 **1.9**，**不要把 PHP 升到 7**——DVWA 1.9 用了 PHP 7 已移除的 `mysql_*` 函数，会直接报错。
2. 虚拟机在 VMware 的 **NAT 网络**里，只有你这台电脑能访问它，这是安全的实验配置。**不要改成桥接模式**，否则等于把一台能 getshell 的靶机暴露到局域网。

## 五、每天 1 小时怎么安排

1. **30 分钟读 1 章**：每读一段就问自己一句——**「这里的用户输入，最后流到了哪里？」**
2. **15 分钟做该章 4 道题**：错题会自动进错题本。
3. **30 分钟动手**：去「实验」页做当阶段实验，再去「DVWA 靶场」把同一个漏洞打一遍、看 Impossible 版的修复代码。
4. 学完点「✅ 学完了」，再回首页看自测清单能勾上几条。

> 24 章按这个节奏大约 4 周。**建议顺序学习**：第 10-16 章依赖第 7-9 章的输入与文件知识；第 18-24 章依赖前面所有漏洞的认知。

## 六、怎么算「学到位了」

首页那份**精通自测清单**（12 条）就是验收标准。其中最关键的几条：

- 能说清危险函数清单：命令执行、代码执行、文件包含、文件操作、反序列化各有哪些；
- 能读懂任意一段 PHP 代码，判断它是否把用户输入拼进了 SQL / 命令 / include / HTML；
- 能识别反序列化漏洞：找到 `unserialize` 入口，说出魔术方法触发链的思路；
- 能独立完成一次审计：找输入点 → 找危险函数 → 追数据流 → 定级 → 给修复方案；
- 能把审计结果写成一份可提交的报告（复现步骤 + 危害 + 修复建议 + 复测方法）。

**真正的验收方式只有一条**：拿一个你没读过的开源 PHP 项目，从入口文件开始审一遍，产出一份报告。

## ⚠️ 安全提醒（务必读）

- 课程涉及 SQL 注入、文件包含、XSS、命令执行、文件上传、反序列化。**目的是让你看懂并修复漏洞，不是让你去打别人。**
- **所有 payload、所有演示代码，只允许在你自己的虚拟机、DVWA、本地靶场里运行。**
- 严禁对任何未授权的真实系统测试——学校网站、公司系统、公网上的任意站点。**不管有没有造成损失，都是违法行为。**
- `code` 文件夹里的示例是**故意有漏洞的**，绝不能部署到公网服务器。
- 审计别人的系统要取得授权；没有授权时只做只读的代码阅读。

## 七、小技巧

- **搜索**能直接定位知识点，忘了在哪一章时特别有用。
- **速查**里的「全局搜索命令」可以直接复制去审计项目（用 ripgrep）。
- **每个漏洞文件都能切换修复版**（改常量或换文件），这是最快理解「漏洞 vs 修复」的方式。
- **DVWA 的 Impossible 级别就是修复版代码**，卡住时点 View Source 对照。
- 进度和成绩存在浏览器本地，清除浏览器数据会重置。
