# code 文件夹说明

这里的每一个文件都能跑起来，对应课程里的具体章节。**放在你自己的虚拟机（192.168.11.133 的 phpStudy）里用。**

## 一、怎么跑

1. 把整个 `code` 文件夹复制到虚拟机的 `C:\phpstudy\WWW\php\` 下
2. 建实验库：在虚拟机里执行 `mysql -u root < setup.sql`
3. 在**本机**浏览器访问：`http://192.168.11.133/php/文件名.php`

## 三、怎么用这些文件学

**每个漏洞文件都设计成「可以切换修复版」**：

| 文件 | 怎么切到修复版 |
|---|---|
| `file_read.php` | 把 `USE_WHITELIST` 改成 `true` |
| `lfi_demo.php` | 把 `USE_WHITELIST` 改成 `true` |
| `rce_demo.php` | 把 `MODE` 改成 `'safe'`（或先试 `'escape'` 看它为什么不够） |
| `upload_demo.php` | 把 `LEVEL` 依次改成 1 → 2 → 3 → 4 |
| `unserialize_demo.php` | 访问时加 `&mode=safe` |
| `unsafe_query.php` → `safe_query.php` | 换一个文件访问即可 |

**推荐用法**：先用漏洞版打一遍（看现象），再切到修复版打同样的 payload（确认失效），最后打开源码对照。<b>这个「打 → 切 → 再打 → 看源码」的循环，就是第 18 章四步法的实操版。</b>

## 四、安全红线

⚠️ **这些文件故意包含漏洞，只允许在你自己的本地虚拟机里运行。**

- 不要部署到公网服务器
- 不要用于测试任何不属于你的系统
- 学习完建议把 `upload_demo.php` 的上传目录清空，避免留下测试文件

这些代码存在的唯一目的，是让你**看懂漏洞长什么样、并学会修掉它**。
