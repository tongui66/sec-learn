🎯 从入门到精通：怎么用这个站

1
读一章（30 分钟）
重点不是背语法，是能回答一句话：「这段代码里的用户输入，最后流到了哪里？」——这就是审计的思维方式。
2
做题（15 分钟）
错题会自动进错题本。错在哪，就说明哪个概念只是"看着懂"。
3
动手（30 分钟）
去「实验」页跑一遍当阶段实验，再去「DVWA 靶场」把同一个漏洞打出来、然后看 Impossible 版的修复代码。只看不练，永远停在「好像懂了」。
4
查手册（随时）
函数记不住查「速查」；名词忘了查「术语」；卡住了看「案例」里的推理过程。
精通判据：不是「背得出函数名」，而是给你一段陌生代码，你能标出输入点、找出危险函数、追出数据流、判断漏洞是否成立，并说出修复方式。首页底部的自测清单就是这张判据表。

🧪 实验与靶场

环境准备（你已经有现成的，别重装）

1
先搞清楚你的 PHP 在哪
本机（跑这个网页的这台 Windows）上没有装 PHP。你真正能跑 PHP 的是 VMware 里的那台虚拟机（192.168.11.133），里面装了 phpStudy（Apache + PHP + MySQL）。
所以别按老教程去下载 PHP 解压到 C:\php——你不需要。
2
把 code 文件夹放进虚拟机
把本机这个 code 文件夹复制到虚拟机里 phpStudy 的网站根目录，通常是 C:\phpstudy\WWW\ 下（可以新建一个 php 文件夹放进去）。
3
用浏览器访问
在本机浏览器打开 http://192.168.11.133/php/hello.php 就能看到运行结果。
改代码就直接改虚拟机里的文件，刷新页面即可，不用重启服务。
4
DVWA 就在同一台虚拟机
http://192.168.11.133/DVWA/（登录 admin / password，级别切到 Low）。第 10-16 章的每个漏洞，都能在 DVWA 里找到对应模块实战。
5
两条注意事项
① 那台虚拟机的 PHP 是 5.4，DVWA 是 v1.9，不要把 PHP 升到 7，会直接报错。
② 虚拟机在 VMware 的 NAT 网络里，只有你这台电脑能访问它——这是安全的，不要改成桥接模式。
红线：第 10-16 章的注入语句、命令执行、文件上传演示，只允许在你自己的虚拟机 / DVWA / 本地靶场里跑。禁止对任何真实网站、学校系统、公司服务器做测试——无论出于什么目的、无论是否造成损失。学攻击原理是为了写出打不动的代码，这条线不能越。

code 文件夹：可运行的示例（每个都能切换修复版）

把整个 code 文件夹复制到虚拟机的 C:\phpstudy\WWW\php\ 下，先执行 setup.sql 建库，然后访问 http://192.168.11.133/php/文件名.php

推荐用法：先用漏洞版打一遍（看现象）→ 切到修复版打同样的 payload（确认失效）→ 打开源码对照。这个「打 → 切 → 再打 → 看源码」的循环，就是第 18 章四步法的实操版。
为什么把 DVWA 单独列一页：它自带 Low / Medium / High / Impossible 四个级别，Impossible 就是安全写法。你不用另找靶场，就能走完「打穿 → 看源码 → 换级别 → 看源码 → 打 Impossible 复测」的完整闭环。

和你手上这台 DVWA 的对应关系：第 10 章 SQL 注入 ↔ SQL Injection，第 11 章文件包含 ↔ File Inclusion，第 12 章 XSS ↔ XSS（三种），第 13 章命令执行 ↔ Command Injection，第 14 章文件上传 ↔ File Upload。课程学一章，就到这里打一遍。
