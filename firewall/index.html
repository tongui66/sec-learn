🧪 实验与靶场

环境准备

1
Windows 防火墙（零成本，马上能练）
Win+R 输入 wf.msc 就是完整实验台；配合 PowerShell 查状态。
2
Ubuntu 虚拟机（练 iptables/NAT 的必需项）
VMware 或 VirtualBox 装 Ubuntu Server，重点：网络模式选 NAT 或仅主机，这样乱配规则也不会影响宿主机。
3
第二台机器或第二个虚拟机（验证连通性用）
很多实验需要"从另一台机器测"，没有它你只能靠猜。
4
快照！快照！快照！
调 iptables 之前先打快照。这是在教你怎么从"把自己锁死"里恢复。
红线：所有实验只能在你自己的虚拟机 / 自己拥有并授权的设备上进行。禁止对学校、公司、公网任何未授权系统做扫描或测试——第 18 章讲的绕过原理，目的是让你会堵，不是让你会翻墙进去。
