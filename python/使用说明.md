# Python 代码审计学习站 · 使用说明

## 这是什么

一套 20 章的自学课程网站，目标有两个：

1. **学完能熟练写 Python**（语言基础 → 标准库与工程 → 并发 → 项目结构）
2. **能看懂别人的源码、能做代码审计**（审计方法论 → 四类高危漏洞 → 框架与供应链 → 实战与报告）

纯静态页面，双击 `index.html` 就能打开，不需要任何服务器。

## 怎么用

### 每天 30 分钟的标准流程

1. 顶部选一节没读完的小节，读完（每节 3-8 分钟）。
2. 打开「练习」，做这一章的 4 道题（选完立即出解析）。
3. 学完一个阶段（每 3-5 章），去「实验」做对应实验。
4. 看到不懂的词，去「术语」查；忘了写法，去「速查」查。
5. 每天点一次打卡。

### 页面结构

| 标签 | 内容 |
|---|---|
| 🏠 首页 | 学习路线图、今日建议、精通自测清单（12 条） |

| 📖 术语 | 60+ 条术语（含英文名、对应的章节） |

### 进度保存与同步

进度存在浏览器本地（localStorage）。换设备时用首页的**导出／导入**按钮搬运进度。

> 清除浏览器数据会丢进度，重要阶段建议先导出一次。

## 红线

课程里有**故意写得不安全的代码**（命令注入、反序列化、SSTI、路径穿越）。

- 它们只允许在**你自己的电脑、自己的虚拟环境**里运行。
- 不要部署到公网，不要对真实网站、学校或公司系统做任何测试。

学攻击原理是为了写出打不动的代码。这条线不能越。

## 环境备忘

- 本机装了 **Python 3.14**，但要用 `py` 命令（`python` 被 Windows 商店占位符拦截）。
- 建虚拟环境：`py -m venv .venv`，激活：`.venv\Scripts\activate`。
- 建议装 **VS Code** + Python 扩展，有补全和调试。
- 审计工具：`pip install bandit pip-audit ruff`。
