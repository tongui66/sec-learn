# code 文件夹 · 可运行示例

每个文件开头的注释里都写了三件事：**怎么跑、应该看到什么、安全等级**。

## 准备

```powershell
cd code
py -m venv .venv
.venv\Scripts\activate
pip install flask requests
```

> 注意：本机要用 `py` 命令，直接敲 `python` 会跳到微软商店。

## 推荐用法

1. **先跑安全版**，确认环境通了。
2. **跑漏洞版**，亲眼看到现象（路径穿越成功、余额变负、注入返回全部记录）。
3. **切到安全版**，用同样的输入再打一次，确认失效。
4. **打开源码对照**，找出那关键的一两行差别。

这个「打 → 切 → 再打 → 看源码」的循环，就是第 15 章四步法的动手版。

## 红线

所有这些示例**只允许在你自己的电脑、自己的虚拟环境里运行**。
不要部署到公网服务器，不要对任何真实系统做测试。
学攻击原理的目的是写出打不动的代码，这条线不能越。

## 自查脚本用法

```powershell
py audit_checklist.py C:\path\to\project
```

它按「代码执行 / 命令执行 / 反序列化 / 模板注入 / SQL 注入 / 危险配置 / 疑似密钥」等分类，
列出命中的文件和行号。**命中的地方必须人工确认数据流，没命中的地方也不能默认安全。**
